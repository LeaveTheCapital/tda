# Repository instructions

## Purpose

- This repository is the canonical project-level documentation and coordination
  space for the TDA live music system.
- Keep implementation code and device-specific configuration in the linked
  component repositories unless a change genuinely belongs at system level.

## Documentation

- Preserve original source notes when turning them into structured documents.
- Clearly distinguish confirmed connections from assumptions or proposed
  changes.
- Keep explanatory prose and the corresponding Mermaid diagram together when
  they describe the same system.
- Use stable, descriptive Mermaid node IDs so diagrams remain easy to edit.
- Link to the relevant component repository for implementation details rather
  than duplicating those details here.

## Verification

- Check that relative Markdown links resolve.
- Check Mermaid blocks for valid syntax after editing diagrams.
- Review diagrams against the source notes and call out unresolved ambiguity.
